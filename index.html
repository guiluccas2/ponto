    Sincronização com o GitHub

    Os dados são salvos automaticamente num arquivo JSON dentro de um repositório seu no GitHub. Configure o mesmo repositório no celular e no computador para usar os dois ao mesmo tempo.

    Como criar o repositório e o token
    1. No GitHub, crie um repositório privado (ex.: ponto-dados) marcando “Add a README”.
    2. Vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    3. Em Repository access escolha “Only select repositories” e selecione só o ponto-dados.
    4. Em Permissions → Repository permissions → Contents, escolha Read and write. Gere e copie o token.
    5. Cole aqui o usuário, o repositório e o token, e toque em “Salvar e conectar”. Repita no outro aparelho.

    O token fica guardado apenas no navegador deste aparelho. Cada salvamento vira um commit, então o repositório guarda o histórico completo das alterações.
